# CampusLink AI - 校园智能助手

## 项目简介

CampusLink AI 是一个基于 RAG（Retrieval-Augmented Generation，检索增强生成）的校园智能问答系统。

系统用于解决新生入学期间大量重复咨询问题，例如：

* 宿舍相关问题
* 食堂相关问题
* 校园卡办理
* 图书馆使用
* 驾校报名
* 奖学金申请
* 校医院服务
* 社团活动
* 校历安排

用户通过自然语言提问：

```text
校园卡丢了怎么办？

第三食堂营业到几点？

驾校在哪里报名？
```

系统自动从校园知识库中检索相关内容，并结合大模型生成准确回答。

# 六、功能模块设计

## 1. 聊天模块

接口：

POST /api/chat

请求：

```json
{
  "question": "校园卡丢了怎么办？"
}
```

返回：

```json
{
  "answer": "根据校园卡管理规定..."
}
```

---

## 2. 文档上传模块

接口：

POST /api/document/upload

支持：

* PDF
* DOCX
* TXT
* Markdown

上传后自动：

* 解析
* 切分
* 向量化
* 入库

---

## 3. 知识库管理模块

接口：

GET /api/knowledge/list

查看：

* 文档名称
* 上传时间
* Chunk数量

支持：

删除文档

---

# 七、文本切分策略

Chunk Size：

```text
500
```

Chunk Overlap：

```text
100
```

示例：

```text
Chunk1

校园卡办理地点位于信息中心...

Chunk2

信息中心工作时间为...
```

# 八、Prompt设计

系统Prompt：

```text
你是学校官方校园助手。

你的职责：

回答学生关于：

- 宿舍
- 食堂
- 校园卡
- 图书馆
- 驾校
- 奖学金
- 校医院

相关问题。

回答必须依据知识库内容。

如果知识库中没有相关内容：

请直接回答：

"目前知识库暂无相关信息，请咨询学校相关部门。"

不要编造答案。
```

用户Prompt：

```text
知识库内容：

{context}

用户问题：

{question}
```

# 九、RAG实现要求

检索方式：

```text
Top K = 5
```

相似度：

```text
Cosine Similarity
```

Embedding：

```python
BAAI/bge-small-zh-v1.5
```

检索返回：

```python
top_5_chunks
```

拼接后送入DeepSeek。
